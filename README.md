# 闻息 · 停云

一款腕表感知中医状态、香氛仪现调香方的情绪舒缓系统。

腕表采集心率与心率变异性，软件侧据此给出「中医状态倾向 + 置信度」，香氛仪按君臣佐使的比例现调香方。作品以非遗药香（香篆技艺，编号 Ⅷ-224）为文化母题，通过气味与光把身体状态「翻译」成可感知的日常陪伴。

> 健康管理工具 · 不构成医疗建议 · 不做诊断与治疗。

---

## 一、运行方式

1. 解压后保持目录完整
2. 双击 `index.html`，用 Edge / Chrome 打开

- 纯静态页面，**无需联网、无需安装、无需构建**
- 全部资源（图片、音频、360° 转台帧）都在 `assets/` 内，本地直接读取

## 二、目录结构

```
闻息_停云/
├─ index.html            页面结构
├─ 录屏演示.bat           一键打开 90 秒自动演示
├─ 打开说明.txt           使用说明
├─ css/                 样式（含昼夜主题、五态配色、样机查看器）
├─ js/                  逻辑（状态判定、组方、动效、音频、桌宠）
└─ assets/              器物水彩图、360° 帧序列、界面纹理与音频
```

## 三、界面与交互

| 界面 | 内容 |
|---|---|
| 今日 | 器物居中；两侧以卡片呈现腕表 / 香氛仪状态、身体数据、当前香方 |
| 调节 | 场景选择（专注 / 放松 / 入睡 / 提神）、扩香强度与时长、声音陪伴、控制权四档、香方配比圆环 |
| 记录 | 本月日历（点香的日子带金点）、心率趋势、香事录 |

**主要交互**

- **点香**：长按香炉 1.8 秒，金色进度环蓄满 —— 花瓣张开、粉色香雾升起、一声脆响；
- **状态**：界面标签、炉光、状态线同源换色；标注置信度与判定依据；
- **调节**：选场景后君臣佐使配比逐帧缓动，像真实换香那样过渡；圆环可拖动微调；
- **夜间**：右上角切换昼夜，画面整体压暗一档，颜色保持奶白本色；
- **360° 查看器**：手环与香炉各 144 帧转台，拖动旋转、滚轮缩放、方向键逐帧。

**快捷键**：`L` 昼夜 ｜ `V` 360° 查看器 ｜ `P` 桌宠 ｜ `M` 声音面板 ｜ `K` 使用边界

## 四、演示

双击 `录屏演示.bat`，或在地址栏加 `?demo=1`：页面出现「开始演示」，点击后播放 90 秒完整功能演示（需真实点击一次，浏览器才允许播放声音）。

## 五、技术实现

- 原生 HTML / CSS / JavaScript，无框架、无构建、无 CDN
- DOM + Canvas 混合渲染：器物质感由 Canvas 合成，动效以 CSS 变量驱动
- 样机展示为 144 帧图序（每帧 2.5°），按需预载，拖动与键盘均可控制
- 音频为 WebAudio 合成音效 + 本地背景音乐，全部离线可用
- 适配桌面端 1280×800 及以上分辨率

## 六、边界声明

- 系统输出「状态倾向 + 置信度」的参考提示，不是证候诊断；
- 血氧连续下降时中止中医判定并提示必要时就医，属安全网；
- 香氛为情绪舒缓体验，不宣称疗效；孕期哺乳期、3 岁以下、哮喘或慢阻肺、癫痫、香精过敏及养猫家庭不建议使用；
- 全部数据在本机运行，不上传服务器。
