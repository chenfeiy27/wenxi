# 闻息 · 非遗药香情绪关怀装置

面向健康人群的**中医状态提示 + 香氛调节**体验装置。腕表采集心率与心率变异性，手机端换算为「中医状态倾向」，香氛仪按君臣佐使的比例现调香方。

> 健康管理工具 · 不构成医疗建议 · 不做诊断与治疗。

---

## 一、这一版包含什么

| 模块 | 内容 |
|---|---|
| 网页端原型 | 今日 / 调节 / 记录 三个界面，顶部标签切换 |
| 昼夜主题 | 白天「晨光香事」宣纸底 · 夜间「雾蓝香事」雾蓝底，墨迹转场切换 |
| 中医状态层 | 四类复合指纹（心火偏亢 / 气血两虚 / 阴虚火旺 / 脾肾阳虚）+ 置信度 |
| 香方系统 | 沉香 / 竹青 / 龙脑 三味，按君臣佐使组方，配比缓动过渡 |

| 桌宠 | 视频画中画悬浮窗，无标题栏、可置顶 |

## 四、算法要点

- **个人基线**：所有判断用「相对基线的偏离」，不用绝对阈值。
- **复合指纹**：单指标不成立，须核心条件 + 支撑条件同时命中。
- **置信度**：按命中项数输出「较高 / 中等 / 低置信」，界面必须显示，不给确定性结论。
- **反证优先**：血氧异常时中止中医判定，优先提示就医，并收起香方建议。
- **可解释**：每次判定可回答「依据哪些数据、偏离多少」。

阈值参数集中在 `js/algorithm.js`（`PARAMS`）与 `js/tcm.js`（`TH`），标注为待校准项。

## 五、技术要点

- 单一 `requestAnimationFrame` 驱动全部动画；`devicePixelRatio` 上限 2。
- 香炉为美术图 + 多段蒙版叠加，点香时逐层点亮。
- 烟气为 Canvas 2D 粒子（上限 120），强度随压力变化。
- 昼夜切换用 SVG `feTurbulence` + `feDisplacementMap` 做毛边墨迹洇开。
- 支持 `prefers-reduced-motion` 降级；`Esc` 关闭任意浮层。

## 六、调试接口
